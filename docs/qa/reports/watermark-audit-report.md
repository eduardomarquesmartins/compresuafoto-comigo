## 1. Executive Summary
The review identified critical security vulnerabilities regarding API key management and webhook validation. Additionally, the watermark generation system showed inconsistencies across different image orientations, and the photo processing workflow presents scalability risks.

## 2. Issues Found

### [CRITICAL] Hardcoded Resend API Key
- **Location:** `server/services/email.js:4`
- **Problem:** The Resend API key is hardcoded as a fallback.
- **Impact:** Potential unauthorized email dispatch and domain reputation damage.

### [CRITICAL] Insecure JWT Secret Fallback
- **Location:** `server/controllers/authController.js` (multiple lines), `server/index.js`
- **Problem:** Uses `'secret'` as a default JWT secret.
- **Impact:** Predictable tokens allowing account takeover.

### [CRITICAL] Missing Webhook Signature Validation
- **Location:** `server/controllers/webhookController.js`
- **Problem:** Processes Mercado Pago notifications without verifying origin.
- **Impact:** Unauthorized order approval via forged requests.

### [MAJOR] Watermark Orientation Inconsistency
- **Location:** `server/services/watermark.js`
- **Problem:** Watermark scale and density varied between landscape and portrait photos.
- **Impact:** Unprofessional and inconsistent branding. (Note: Initial fix applied by Orion, needs validation).

### [MAJOR] Synchronous Photo Processing
- **Location:** `server/controllers/photoController.js`
- **Problem:** Heavy image processing (Sharp + Rekognition) happens within the HTTP request cycle.
- **Impact:** Risk of request timeouts and high resource contention.

### [MINOR] Generic Error Handling
- **Location:** `server/index.js`
- **Problem:** Global error handler returns generic 500 without context.
- **Impact:** Difficulties in troubleshooting production issues.
